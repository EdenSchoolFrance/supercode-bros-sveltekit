🎮 Balise <input> — l'attribut name détermine le type :
  👾 name="goomba" → ennemi Goomba (saute dessus pour le vaincre)
  🐢 name="koopa" → ennemi Koopa Troopa (tortue verte, saute dessus)
  🔥 type="boss" name="bowser" → Boss Bowser · taille ×2 · 3 coups · boules de feu toutes les 3 s
  🍄 name="mario" → point de départ de Mario (1 seul par niveau)
  Sans name="mario", Mario apparaît au-dessus du 1er bloc de sol.

🎁 Balise <h3> — l'attribut data-item détermine l'objet libéré :
  🪙 data-item="coin" → pièce (+50 pts) · défaut
  ⭐ data-item="star" → étoile · invincibilité 5 s avec aura arc-en-ciel
  🍄 data-item="mushroom" → champignon · Mario grandit · +1 ❤️
  🌸 data-item="flower" → fleur · Mario rose · +1 ❤️ · touche E = boule de feu
